# 五、MOEA/D 个体怎么编码：这是整个实现最关键的地方

不要搞一个：

$$
x\in\{0,1\}^{2615}
$$

然后直接交叉变异。

那样大量个体都会：

* 某箱没送；
* 某箱送两次；
* deadline 不可行；
* UAV 并发超限；
* 电池超限。

## 推荐表示

每个 MOEA/D 个体保存：

$$
\boxed{
X=
\left(
S,\mathbf s,F
\right)
}
$$

其中：

### 1. $S$

当前 CP-SAT 输出的一套运输任务集合：

$$
S=\{k_1,k_2,\ldots,k_m\}
$$

例如：

```python
task_ids = frozenset([
    "R000234",
    "R000241",
    "R000490",
    ...
])
```

### 2. $\mathbf s$

这些任务当前的开始时刻，用来给下一次 CP-SAT `AddHint()`。

### 3. $F$

目标向量：

```python
objectives = (
    n_sorties,
    energy_kwh,
    cmax_s,
)
```

但是注意：

> **$S$ 只是 MOEA/D 当前维护的运输方案骨架，不是下一代必须原封不动采用的最终任务。**

下一步 CP-SAT 可以局部改变 $S$。

这样就符合你要求的：

$$
\boxed{
\text{MOEA/D管方案搜索}
+
\text{CP-SAT管具体任务选择}
}
$$

# 六、交叉不要普通 one-point crossover

这里建议设计成非常适合你问题的：

$$
\boxed{\text{Consensus + Destroy + CP-SAT Repair}}
$$

这比普通 GA 交叉合理很多。

假设两个父代：

$$

$$

首先求共同任务：

$$

=
S^{(1)}\cap S^{(2)}
$$

父代都选择的任务优先保留。

例如：

```text

Parent 2:
A B C X Y F G Z
```

共同部分：

```text

```

这些任务先固定。

# 九、从 2615 个任务里构造局部候选集

设已经固定的任务集合：

$$

$$

它们覆盖的箱不能再次被其他任务覆盖。

自由货箱集合：

$$

$$

局部候选任务只保留：

$$
\boxed{

\{k:B_k\subseteq U\}

非常重要。

不是：

$$

而必须：

$$

否则新任务可能同时运输一个已经被固定任务运输的箱，导致重复覆盖。

# 十四、最大的修改：CP-SAT 不再只有 N/E/T 字典序目标

你现在：

```python
stage_map = {
    "N": ...,
    "E": ...,
    "T": ...,
}
```

新的 MOEA/D 内层要支持：

$$
\lambda=
(\lambda_N,\lambda_E,\lambda_T)
$$

建议使用 **augmented Tchebycheff**。

MOEA/D 标量子问题：

$$
g(X|\lambda,z^*)
=
\max_{i}
\left\{
\lambda_i
\frac{f_i(X)-z_i^*}{r_i}
\right\}
+
\rho
\sum_i
\lambda_i
\frac{f_i(X)-z_i^*}{r_i}
$$

其中：

$$
\rho=0.01
$$

即可。

相比简单：

$$
\lambda_NN+\lambda_EE+\lambda_TC_{\max}
$$

Tchebycheff 更适合生成非凸 Pareto 前沿。

# 十五、CP-SAT 里怎么实现 Tchebycheff

因为 CP-SAT 只能处理整数。

你已经有：

```python
ENERGY_SCALE = 10000
```

所以：

$$
E^{int}=10000E
$$

定义：

```python
n_sorties
energy_units
cmax
```

再定义：

```python
g = model.NewIntVar(0, BIG_M, "tcheby")
```

设尺度：

$$
r_N,\quad r_E,\quad r_T
$$

根据三个 anchor 初始化。

然后整数化系数：

```python
cN = round(SCALE * lambda_N / rN)
cE = round(SCALE * lambda_E / rE)
cT = round(SCALE * lambda_T / rT)
```

加入：

```python
model.Add(
    g >= cN * (n_sorties - zN)
)

model.Add(
    g >= cE * (energy_units - zE)
)

model.Add(
    g >= cT * (cmax - zT)
)
```

最终：

```python
model.Minimize(
    BIG_WEIGHT * g
    + cN * (n_sorties - zN)
    + cE * (energy_units - zE)
    + cT * (cmax - zT)
)
```

这就是真正的：

$$
\boxed{\text{MOEA/D 子问题}\rightarrow\text{CP-SAT 精确求解}}
$$

# 二十、MOEA/D 更新

新方案为：

$$
Y
$$

更新 ideal point：

$$
z_j^*
=
\min(z_j^*,f_j(Y))
$$

然后对邻居：

$$
j\in B(i)
$$

计算：

$$
g(Y|\lambda_j,z^*)
$$

和：

$$
g(X_j|\lambda_j,z^*)
$$

若：

$$

\le

则：

X_j\leftarrow Y
$$

$$

$$

即一个 offspring 最多替换两个邻居。

# 三十、每次内层求解时间不要给 200 秒

MOEA/D 要调用很多次 CP-SAT。

第一版建议：

```python
population_size = 45
generations = 40
local_time_limit = 1.0 ~ 2.0 s
workers = 1 or 2
```

理论最多：

$$
45\times40=1800
$$

次局部求解。

但因为：

* 局部候选规模很小；
* 有 cache；
* 很多父代相同；
* 有 start hints；

实际比 1800 次完整 CP-SAT 快非常多。

# 三十八、完整伪代码可以直接按这个实现

```text
Algorithm Q2-MOEAD-CP-SAT

Input:
    reduced candidate task set K
    box set B
    UAV resources
    battery resources

1. Run CP-SAT baselines:
       X_N = N-opt
       X_E = E-opt
       X_T = T-opt

2. Generate decomposition weights:
       Λ = {λ1,...,λM}

3. Build weight neighborhoods B(i)

4. Initialize population:
       for each λ_i:
           choose nearest anchor
           apply local destroy
           child ← CP-SAT-Repair(anchor, λ_i)

5. Initialize:
       ideal point z*
       external archive EP

6. for generation = 1,...,G:

       for i = 1,...,M:

           select X_p1, X_p2 from B(i)

           S_common =
               tasks(X_p1) ∩ tasks(X_p2)

           D =
               tasks(X_p1) △ tasks(X_p2)

           randomly destroy 1~3
           additional common tasks

           construct fixed tasks S_fix

           U =
               boxes not covered by S_fix

           K_U =
               {k | boxes(k) ⊆ U}

           Y ← CP-SAT(
                   fixed=S_fix,
                   candidates=K_U,
                   weight=λ_i
               )

           if Y infeasible:
               continue

           evaluate:
               F(Y)=(N,E,Cmax)

           update z*

           update EP

           for j ∈ B(i):
               if g(Y|λ_j,z*)
                  <= g(X_j|λ_j,z*):

                   X_j ← Y

                   replacement_count += 1

               if replacement_count >= nr:
                   break

7. Final CP-SAT polishing
   for Y ∈ EP

8. Remove duplicate/dominated solutions

9. Independent validation

Output:
    Pareto front EP
```

## 最推荐的具体实施顺序

第一步先**不要写 MOEA/D 主循环**，先把 `cp_sat_scheduler.py` 重构出一个：

```python
solve_local_subproblem(...)
```

确保：

> 给定固定任务 + 自由货箱 + 权重 $\lambda$，能够由 CP-SAT 返回一套完整可行方案。

第二步，用 N-opt 人工 destroy 2 个任务测试这个函数，看它能不能重新组合货箱并保持全部约束。

第三步，再实现 `moead.py` 的权重、邻域、Tchebycheff、archive。

第四步接上 45 个子问题、40 代搜索。

第五步最后加 cache、convergence、final polishing。

**这个顺序最稳。**如果第一步 `solve_local_subproblem()` 没有完全正确，直接开始写完整 MOEA/D，后面很难判断到底是进化算法的问题还是 CP-SAT repair 的问题。
