# Q1 固定机型与混合机型统一实验

统一入口为 `python code/Q1.py`，先完成固定机型分析，再完成混合机型三个单目标。`Q1_mixed_type_experiment.py` 仅为旧入口的兼容包装，混合组批实现和物理模型调用均在 `Q1.py`。运行需要 pandas、NumPy 与 SciPy。

固定机型结果文件均以 `Q1_fixed_` 开头，包括最大安全载荷、三个单目标、Pareto、偏好方案、策略比较和安全余量敏感性。混合机型结果文件均以 `Q1_mixed_` 开头。

混合部分分别最小化往返架次数、总运输能耗、累计作业时间。每个服务区独立组批；每架次从 A、B、C 中选择一个机型，货箱不可拆分，必须恰好运输一次。候选批次复用固定机型的质量、体积、可用电量约束及同一物理模型，对每个服务区使用精确的子集动态规划求解。

并列解顺序为：N-opt 按架次→能耗→累计时间，E-opt 按能耗→架次→累计时间，T-opt 按累计时间→能耗→架次。所有指标均为各服务区结果相加。

输出：

- `Q1_mixed_N_opt_plan.csv`、`Q1_mixed_E_opt_plan.csv`、`Q1_mixed_T_opt_plan.csv`：三个目标的逐架次方案。
- `Q1_mixed_objectives.csv`：三个目标的逐服务区和 `all` 总计，含各机型架次数。
- `Q1_mixed_comparison.csv`：A、B、C 单机型 E-opt 与混合机型三个目标的逐服务区及总计对照。
- `Q1_mixed_manifest.json`：输入文件校验值、运行命令和实验口径。

混合实验允许每架次自由选择机型，未加入机队数量、共享电池、发车时序、首批物资或交付期限约束。`T_total_s` 是各架次作业时间之和，不是全任务完成时刻。
