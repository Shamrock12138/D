# 术语表格 —— Q4

| 术语或符号 | 含义 | 单位或范围 |
|---|---|---|
| S | 15 个服务区集合 | S001–S015 |
| T、R | Q3 冻结运输架次、中继任务集合 | 不重求解 |
| V_t | 架次 t 的服务区访问集合 | S 的子集 |
| T_r | 中继任务 r 保障的完整运输架次集合 | T 的子集 |
| B_b、M | 不可拆服务区块及块数 | M≤15 |
| K、G_g | 组数及第 g 个任务组 | K∈{2,3} |
| x_bg | 块 b 是否分入组 g | 0 或 1 |
| I_j | 固定任务的半开资源占用区间 | 秒，[开始,结束) |
| N_gr | 组 g 最少配置的 r 类资源数 | 台或组 |
| N⁰_r | 不分组固定 Q3 时间表的最少 r 类资源数 | 台或组 |
| C_r、H_r | 分组后的总配置与新增冗余 | 台或组，H_r=C_r−N⁰_r |
| I_r、D_r、S_r | 现有库存、采购缺口、库存剩余 | 台或组 |
| W_g、CV_W | 组作业时长、组间变异系数 | 秒、无量纲 |
| TUAV_A/B/C | 三型运输无人机资源 | 架 |
| TBAT_A/B/C | 三型共享运输电池资源 | 组 |
| RUAV、REC | 中继无人机、中继能源组件 | 架、组 |

字段约定：`sortie_id` 是 Q4 的统一运输架次 ID；`visit_order` 是冻结访问序列；`charge_end_s`、`uav_release_time_s`、`energy_release_time_s` 是 Q3 已核定的占用结束时刻。所有时间字段均为相对于同一调度起点的秒数。
